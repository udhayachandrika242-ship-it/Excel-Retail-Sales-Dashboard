# Retail Sales Dashboard using Excel

## Project Overview
This project analyzes retail sales data using Microsoft Excel.

## Tools Used
- Microsoft Excel

## Work Done
- Cleaned the sales dataset.
- Removed duplicate records.
- Calculated Total Sales using Unit Price and Quantity.
- Created Pivot Tables to summarize sales data.
- Created KPI cards for Total Sales, Total Quantity, and Total Orders.
- Created charts to analyze category-wise sales, region-wise sales, payment methods, and monthly sales trends.

## Objective
The objective of this project is to understand sales performance and identify useful business insights through an Excel dashboard.Retail Sales Dashboard using Microsoft Excel with formulas, Pivot Tables, KPI cards, and charts to analyze sales performance.
